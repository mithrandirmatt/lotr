# Qwen3.5's hybrid architecture uses Gated DeltaNet (linear-attention) blocks
# for 28/32 layers. Without this, transformers falls back to a pure-PyTorch
# implementation of the DeltaNet recurrence during training, which is
# drastically slower (observed: training never completed even a single step).
# flash-linear-attention has official ROCm support (Triton-based kernels);
# the main pip install command already targets the rocm7.2 wheel index, which
# satisfies this package's torch/triton requirement without reinstalling the
# pinned torch build. If the "fast path is not available" warning persists
# after this, also try `causal-conv1d` (CUDA/HIP source build, ROCm-patched
# but not added here yet since it requires compiling from source).
flash-linear-attention[rocm]
